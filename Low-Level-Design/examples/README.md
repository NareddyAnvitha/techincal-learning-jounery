# SOLID Principles – Java Examples

This folder contains practical Java implementations of all five SOLID principles.

## Programs Available

| No. | File | Principle |
|---|---|---|
| 1 | SRPExample.java | Single Responsibility Principle |
| 2 | OCPExample.java | Open/Closed Principle |
| 3 | LSPExample.java | Liskov Substitution Principle |
| 4 | ISPExample.java | Interface Segregation Principle |
| 5 | DIPExample.java | Dependency Inversion Principle |

## How to Run

Compile a Java program:

```bash
javac SRPExample.java
```

Run it:

```bash
java SRPExample
```

Replace `SRPExample` with the class name of the program you want to execute.

## Learning Objectives

- Understand all five SOLID principles.
- Apply object-oriented design principles using Java.
- Write maintainable and reusable code.
- Understand loose coupling and high cohesion.
- Improve low-level design and interview preparation.
