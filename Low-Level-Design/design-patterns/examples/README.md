# Java Design Pattern Examples

This folder contains practical Java implementations of commonly used software design patterns.

## Programs Available

| No. | Program | Pattern Category |
|---|---|---|
| 1 | SingletonExample.java | Creational |
| 2 | FactoryExample.java | Creational |
| 3 | BuilderExample.java | Creational |
| 4 | ObserverExample.java | Behavioral |
| 5 | StrategyExample.java | Behavioral |

## Design Pattern Categories

### Creational Patterns
- Singleton
- Factory
- Builder

### Structural Patterns
- Adapter
- Decorator
- Facade

### Behavioral Patterns
- Observer
- Strategy
- Template Method

## How to Run

Compile:

```bash
javac SingletonExample.java
```

Run:

```bash
java SingletonExample
```

Replace the class name with the program you want to execute.
