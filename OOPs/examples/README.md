# OOPS Java Practical Examples

This folder contains Java programs demonstrating the major Object-Oriented Programming concepts.

## Programs Available

| No. | Program | Concept |
|---|---|---|
| 1 | EncapsulationExample.java | Encapsulation |
| 2 | InheritanceExample.java | Inheritance |
| 3 | PolymorphismExample.java | Runtime Polymorphism |
| 4 | AbstractionExample.java | Abstraction |
| 5 | InterfaceExample.java | Interfaces and Multiple Inheritance |
| 6 | ConstructorOverloadingExample.java | Constructor Overloading |
| 7 | MethodOverloadingExample.java | Compile-Time Polymorphism |
| 8 | MethodOverridingExample.java | Runtime Polymorphism |

## How to Run the Programs

### Step 1: Install Java

Install the Java Development Kit (JDK).

### Step 2: Open a terminal

Navigate to the folder containing the Java file.

### Step 3: Compile the program

```bash
javac EncapsulationExample.java
```

### Step 4: Run the program

```bash
java EncapsulationExample
```

Replace `EncapsulationExample` with the name of the program you want to execute.

## Learning Objective

Understand OOPS concepts through simple Java programs and practical examples.
